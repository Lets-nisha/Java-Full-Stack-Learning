What is CSS?

CSS (Cascading Style Sheets) an is a stylesheet language used to define how HTML or XML documents are presented across different media like screens, print, or speech. It controls layout, colors, fonts, spacing, and responsiveness, enabling developers to separate content from design for cleaner, maintainable code. A CSS style is essentially a rule that specifies how selected HTML elements should appear. Each rule consists of a selector selector (targets elements) and a declaration block (contains property-value pairs).

Why Use CSS?

CSS is used because it controls a website’s visual design—colors, layout, fonts, spacing, and responsiveness—separating content (HTML) from presentation for easier maintenance and better user experience.
